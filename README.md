**농담은 못난이 농산물의 새로운 유통 채널을 제안합니다.**  
생산자와 요식업 자영업자를 연결하고, 소비자에게는 친환경적 소비를 경험하게 합니다.

---

## 📌 프로젝트 개요

> 못난이 농산물의 가치 재발견,  
> 못난이 농산물과 로코노미(Local + Economy)가 만나  
> 지역 경제와 환경을 동시에 살리는 서비스.

- **생산자**는 못난이 농산물을 직접 등록하여 판매하고
- **요식업자**는 저렴한 가격에 안정적으로 구매해 메뉴를 개발하며
- **소비자**는 ‘농담 식당’을 통해 지속 가능한 식문화를 경험합니다.

---

## 🎯 주요 기능

- **농담 마켓**: 못난이 농산물 등록 및 검색 기능
- **1:1 채팅**: 생산자와 요식업자 간 직접 소통
- **농담 식당**: 해당 농산물로 요리하는 식당 검색
- **인증 시스템**: 사업자 인증 및 후기, 별점
- **AI 챗봇**: ChatGPT API로 사용자 편의성 향상

## 🧩 기술 스택

### Frontend
- **React**, **React Router**, **Vite**
- **styled-components**, **MUI**, **React Query**
- **Kakao Maps SDK**, **Axios**

### Backend
- **Spring Boot**, **JWT + OIDC 인증**, **QueryDSL**
- **MySQL + JPA**, **Swagger API 문서화**

### DevOps & Infra
- **AWS EC2 / S3 / RDS**, **Docker**, **Nginx**
- **GitHub Actions**로 CI/CD 구성

## 🌱 프로젝트 기대효과
